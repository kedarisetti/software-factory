## Recently changed

- [Public API fields are snake_case in JSON](conventions/api/public-api-fields-are-snake-case-in-json.md): Rust structs keep snake_case and serde needs no rename.
- [Migrations are forward only and reviewed by the data owner](conventions/database/migrations-are-forward-only-and-reviewed-by-the-data-owner.md): We never write down migrations.
- [Dependencies are added with cargo add and justified in the PR](conventions/dependencies/dependencies-are-added-with-cargo-add-and-justified-in-the.md): A new crate needs a sentence in the pull request: what it does, why std or an existing dependency is not enough, and it…
- [Errors use thiserror in libraries and anyhow at the edge](conventions/errors/errors-use-thiserror-in-libraries-and-anyhow-at-the-edge.md): Library crates define typed errors with thiserror so callers can match on them.
- [Feature flags live in flags.toml and default off](conventions/flags/feature-flags-live-in-flags-toml-and-default-off.md): New behaviour ships behind a flag declared in config/flags.toml.
- [React components are function components with hooks only](conventions/frontend/react-components-are-function-components-with-hooks-only.md): The dashboard in ledger-ui has no class components.
- [Commit messages follow conventional commits](conventions/git/commit-messages-follow-conventional-commits.md): Use feat, fix, chore, docs, refactor and test prefixes.
- [Handlers return ApiError never raw status codes](conventions/http/handlers-return-apierror-never-raw-status-codes.md): Every axum handler returns Result<Json<T>, ApiError>.
- [Log with tracing spans and structured fields](conventions/logging/log-with-tracing-spans-and-structured-fields.md): Use tracing, not println or log.
- [Money is integer minor units](conventions/money/money-is-integer-minor-units.md): All amounts in ledgerd are i64 minor units (cents) paired with an ISO 4217 currency code.
